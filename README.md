# L4D2 Android Launcher v0.1

Android 10+ experimental launcher UI. Does **not** run Left 4 Dead 2 yet. No game files, Wine, or Box64 are included.

## Build
Upload all files/folders to a GitHub repository preserving paths. Open Actions > Build Android APK > Run workflow. Download the APK from the run's Artifacts section.

## Status
- Folder picker persists a document-tree URI.
- Does not validate game files yet.
- PLAY is a placeholder.
- Wine/Box64 and graphics runtime are future research goals.
